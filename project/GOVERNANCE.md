# Project Governance

This is a simulated Mettelo client engagement using official public/open data. Participants must not claim access to a real confidential client.

## Data Governance
Document provenance, owner/publisher, version, glossary, critical fields, quality rules, lineage, transformations, metric ownership and limitations.

## Responsible Interpretation
High complaint volume does not automatically mean poor conduct because firm size and product mix matter. Analytical flags are not regulatory findings and must be contextualised.

Any prioritisation, score or forecast is decision support unless explicitly justified otherwise. Separate analytical evidence from professional, policy, statutory or executive judgement.

## GitHub
The delivery repository is created under the Mettelo GitHub organisation. Add team members individually. Use issues, branches, commits, PRs and reviews where practical. Never commit credentials or prohibited personal information.
